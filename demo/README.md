# Klystr product tour

Use these screenshots in numeric order for a concise product walkthrough:

1. `01-topology-overview.png` — open the live topology workspace with the built-in mock cluster.
2. `02-topology-filtered-checkout.png` — search the graph to focus on a specific workload.
3. `03-rbac-control.png` — review ServiceAccount identities and effective permissions.
4. `04-image-analysis.png` — inventory the container images running across the cluster.
5. `05-image-inspection.png` — inspect an individual image.
6. `06-manifest-import.png` — import YAML, JSON, or Helm-folder manifests for declared-state analysis.
7. `07-security-posture.png` — review the summarized security posture.
8. `08-security-attack-paths.png` — move into the RBAC attack-path investigation view.

All frames were captured from the production build using mock cluster data, so the sequence is repeatable without Kubernetes credentials.
